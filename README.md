
# Python Student Management System

A simple Student Management System built using Python. This project helps manage student records through a command-line interface.

## Features

- Add new students
- View all student records
- Search students by ID
- Update student marks
- Delete student records
- Calculate average marks
- Find the student with the highest marks
- Store records permanently using JSON

## Technologies Used

- Python 3
- JSON
- Python built-in libraries

## Project Structure

```text
python-student-management-system/
├── main.py
├── README.md
└── students.json
```

Note: The students.json file is created automatically when records are saved.

## Installation and Usage

1. Install Python 3 on your computer.
2. Download or clone this repository.
3. Open the project folder in your terminal.
4. Run the following command:

```bash
python main.py
```

On some systems, use:

```bash
python3 main.py
```

5. Select an option from the menu to manage student records.

## How It Works

The program stores student information, including student ID, name, and marks. It uses Python functions to perform different operations and saves the records in a JSON file.
